Cober Design System

Tokens de color, tipografía, espaciado, radios, sombras y componentes base de Cober — listo para adjuntar a Figma IA como Design System de referencia. La paleta de color es la oficial que definiste; el resto de los tokens se generó a partir de ella para que el sistema quede completo y utilizable.

02 — Fundaciones

Tipografía Generado

No había tipografía definida, así que se propone Plus Jakarta Sans como fuente única de interfaz (títulos y cuerpo, pesos 400 a 800 — geométrica, muy legible en pantallas chicas, con buen soporte de tildes/ñ) e IBM Plex Mono para datos tabulares, montos y códigos.

03 — Fundaciones

Espaciado Generado

Escala de base 4px. Usá siempre estos valores para paddings, gaps y márgenes — nunca números sueltos.

05 — Fundaciones

Iconografía Generado

Sin set de íconos definido. Convención propuesta: trazo de 1.75px, grilla de 24×24, esquinas redondeadas, siempre outline salvo en estado seleccionado (relleno con Brand 800). Cualquier librería de íconos "line/outline" compatible (Lucide, Phosphor, Feather) sirve — lo importante es no mezclar grosores de trazo.
